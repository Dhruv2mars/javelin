# Security Policy

## Supported versions

Javelin has no release yet. Only the latest commit on `main` is supported. Fixes land on
`main` and are not backported. This will change when the first release is published.

## Reporting a vulnerability

Do not open a public issue or pull request for a security problem.

Report it privately through GitHub's private vulnerability reporting:
[Security → Report a vulnerability](https://github.com/Dhruv2mars/javelin/security/advisories/new).

Include:

- the affected commit and operating system, and the filesystem if relevant;
- steps to reproduce, or a minimal test case;
- the impact you expect, such as data loss, corruption of a World or Layer, or Git
  being invoked by Javelin code.

## What to expect

This is a pre-1.0 project maintained on a best-effort basis, so these are targets, not a
service commitment:

- Acknowledgement within 5 business days.
- An initial assessment, including whether the report is accepted, within 14 days.
- A fix or mitigation on `main` as soon as it is verified.

Please keep the details private until a fix is available or the maintainer agrees on a
disclosure date.
