# Javelin CLI

Install the native Javelin command:

```sh
npm install --global javelin-cli
javelin version
```

This package bundles Javelin for Apple Silicon macOS, x64 Ubuntu 24.04 or newer (glibc; Alpine is unsupported), and x64 Windows. It has no install script and makes no download during installation.

Documentation and source: https://github.com/Dhruv2mars/javelin
